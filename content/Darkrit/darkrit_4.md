# Day 23 - More SDL_GPU

I'm still doing SDL_GPU. I've been told that the biggest advantage is being able to fill command buffers from different threads and reuse them across frames for the most performance agains. Maybe that's good but I'm still thinkin OpenGL is more than enough. It's just a shame that is being deprecated and unsupported, slowly dying. I think such a nice simple API should be supported. I think I would achieve my goal faster with OpenGL, but that means I might have to change API in the future, I wouldn't be able to support MacOS... I'll try to stick to SDL_GPU for a while more
